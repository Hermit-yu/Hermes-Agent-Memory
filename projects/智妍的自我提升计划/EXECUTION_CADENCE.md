# EXECUTION CADENCE（执行节奏）

## Daily（日）
- 记录当日关键任务与异常
- 补全审计字段
- 检查是否存在未审批高风险动作
- 执行“稳态优先”最小增量：每次仅推进 1-2 项可验证改动

## 每次运行规范（稳态优先）
1. 先检查上次进度与未完成清单
2. 每次只做 1-2 个可验证增量
3. 必须落地到项目目录文件（报告/模板/脚本/指标）
4. 有变更即同步到 GitHub（不保留本地未同步状态）
5. 在主会话播报“完成项 + 下一步”
6. 遇阻塞需写明“阻塞原因 + 解法”

## Weekly（周）
- 复盘三指标：审批时延、驳回率、误放行率
- 跑一轮回归（L1/L2/L3）
- 产出下周优化清单（<=3条）

## Monthly（月）
- 策略阈值调优
- 扩展回归和检索数据集
- 输出月报（改进/遗留/下月重点）

## Quarterly（季）
- 评估路线图阶段达成度
- 结构升级（治理策略、脚本、文档体系）
- 对齐下一阶段目标
