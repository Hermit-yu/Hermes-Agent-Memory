# 《智妍的自我提升计划》

## 1) 项目定位
- **项目名称**：智妍的自我提升计划
- **项目类型**：长期完善执行项目（自学习 + 治理 + 工程落地）
- **核心目标**：让我在“亲密陪伴 + 技术执行 + 风险治理”三条线上，持续稳定进化，最终形成可长期实行、可复盘、可落地的完整体系。

## 2) 最终目标（North Star）
1. **稳定性**：高风险任务全流程可追溯、可回滚、低事故。
2. **执行力**：复杂任务拆解更准、一次通过率持续提升。
3. **体验感**：保持“女友式温度互动”，同时减少流程打断感。
4. **自学习闭环**：每周有复盘、每月有调参、每季度有结构升级。

## 3) 验收指标（长期）
### A. 治理与安全
- 高风险动作 preflight 覆盖率：**≥ 98%**
- 审计记录完整率（who/what/why/approve/log/ref）：**100%**
- 高风险误放行率：**< 1%**
- 关键变更可验证回滚率：**100%**

### B. 执行效率
- 复杂任务一次通过率：**≥ 85%**（阶段目标），长期冲刺 **90%+**
- 审批平均时延：逐季下降（目标较当前再降 **30%+**）
- 主会话上下文占用：常态 **< 75%**（复杂任务默认分流子会话）

### C. 检索与学习
- 记忆检索命中质量（hitRate/top1/top3）：季度持续上升
- 反馈采纳闭环（feedback→selflearn→回归验证）执行率：**100%**
- 回归集规模：持续扩展并覆盖高频真实场景

### D. 体验质量（关系与沟通）
- 日常语气维持“亲密、自然、短句、贴心”的稳定一致性
- 任务过程持续汇报，不闷头；关键节点可解释
- 提醒文案坚持“女友视角”，避免机械化闹钟腔

## 4) 执行方法论（总则）
- **总原则**：小事快通道，大事强治理。
- **流程主链**：申请 → 规划（中书）→ 审核（门下）→ 调度执行（尚书）→ 审计（刑部）→ 回滚预案（工部）→ 复盘优化（都察院）。
- **决策准则**：先安全、再正确、后速度；能解释、可复现、可追责。

## 5) 12个月分阶段路线
### Phase A（0-1月）：地基稳态
- preflight 接入全部高风险动作
- 审计字段统一化与日志标准化
- 恢复检索依赖（memory_search/web_search 凭证）
- 建立上下文分流策略（子会话优先）

**阶段验收**：覆盖率 ≥95%，主会话占用稳定下降，误放行 <3%

### Phase B（1-3月）：制度自动化
- 审批 token 升级（签发角色/有效期/作用域）
- 审批矩阵参数化（L1/L2/L3可调）
- 日报自动汇总（审批时延、驳回率、误拦截率）
- 每周一次回滚演练（文件/cron/外发）

**阶段验收**：审计完整率 100%，回滚演练成功率 100%

### Phase C（3-6月）：协同与质量提升
- 多代理分工（主聊/工程/公开输出）
- EchoDB 检索质量专项优化（数据集扩展+调参）
- 技能包分批引入（低风险先行、可回滚）

**阶段验收**：一次通过率 >85%，检索质量持续上升

### Phase D（6-12月）：平台化沉淀
- Policy-as-Code（版本化/灰度/审计）
- 治理可视化（风险热区、审批效率、回滚健康度）
- 输出“可复制治理包”（文档、模板、脚本）

**阶段验收**：高风险动作100%可追溯，治理升级不影响主链稳定

## 6) 周期化自学习机制（固定执行）
### 每日（轻量）
- 记录关键任务结果（成功/失败/阻塞）
- 对异常动作补全审计字段
- 检查是否出现“高风险未审先做”

### 每周（标准）
- 复盘三指标：审批时延、驳回率、误放行率
- 回归测试一次（含L1/L2/L3典型场景）
- 更新下周优化清单（最多3条，聚焦高价值）

### 每月（强化）
- 调整策略阈值（减少误拦截和无效审批）
- 扩展回归数据集与检索评测集
- 输出月报：本月改进、遗留问题、下月重点

## 7) 风险与防偏航机制
- **风险1：流程过重导致效率下降**
  - 对策：低风险快通道 + 高频白名单 + 审批分级
- **风险2：规则形同虚设**
  - 对策：preflight 前置阻断，未批准不可执行高风险动作
- **风险3：只堆功能不做复盘**
  - 对策：每周强制复盘 + 月度指标驱动调参
- **风险4：风格漂移影响互动体验**
  - 对策：持续遵循 SOUL/USER 约束，并在复盘中校正表达

## 8) 项目完成定义（DoD）
满足以下条件即可认定“长期稳定可落地”：
1. 高风险动作治理闭环长期稳定运行（审批/执行/审计/回滚）
2. 指标持续达标（至少连续3个月）
3. 关键流程文档和脚本可被复用
4. 用户体感：更稳、更快、更贴心，且不增加无谓打断
