## 一、著作/课程体系全貌（★★ 学院官网 + 学生整理）

倪海厦（1954-11-11 ~ 2012-01-19），台湾出生、美国行医，汉唐中医创始人（美国佛州）。
毕生输出不是市面出版的"书"，而是**自编讲义 + 配套录影课程**两大体系：

### 人纪（医学，五部经典讲义，自编教材非视频转写）
1. **针灸**（《针灸甲乙经》讲解，文字实录：倪师口述、学生编写）
2. **《黄帝内经》** 讲义（素问+灵枢，11 张 DVD 量）
3. **《神农本草经》** 讲义
4. **《伤寒论》** 讲义（8 张 DVD 量）
5. **《金匮要略》** 讲义
- 定位：中医临床完整心法，主张"五部经典足够解决人类疾病"，反对学杂。
- 自学顺序（Gitee 官方传承仓 README）：**针灸→黄帝内经→神农本草经→伤寒论→金匮要略**，配合 B 站视频。

### 天纪（天文地理玄学，1994 年摄制，2010 年后才发行）
- 三卷：**天机道**（易经、紫微斗数、奇门、铁板神数、麻衣相法…）、**地脉道**（阳宅风水、罗经）、**人间道**（六壬、子平法）
- 内容范围：易经 64 卦、紫微斗数、阳宅风水、看相、测字、六壬奇门
- 发行动机（学院官网引《黄帝内经》第七十五篇"着至教论"）：**"上知天文，下知地理，中知人事"**，学中医之外懂周易六壬才算大医。

### 三"纪"世界观（★★★ 倪师原话，finalhopes 博客课程实录）
> "人纪就是人间社会上的伦理规范、法律规范；地纪是史学家陈述事实的记录；天纪是自然法则——真理，已经被证实的道理，不需要你去证实。"
- 核心主张：**天、地、人三纪是一个整体，单独学一个不全面**（学生心得 ★：医理、命理、地理"三理"，读书人要都懂；孝道是其背后动机 ★）。

## 二、智识谱系与推荐书单（★★★ 本人开书单）

倪师开的天纪参考书单 15 种（断易天机/紫微斗数全书/铁板神数/麻衣神相/罗经使用方法…，多为台湾武陵出版社版本）。
推荐的中医生涯谱系：张仲景（伤寒杂病论本尊）→ 郑钦安（扶阳真传）→ 曹颖甫/陆渊雷（经方实证）→ 李可（重证危证）→ 唐容川（中西汇通《血证论》）。
《圆运动的古中医》（彭知义）也在其推荐序列中。

## 三、反复出现 ≥3 次 的核心论点（真信念候选，待 Agent 2-5 交叉验证）

1. **经方至上 / 经典唯一论**："中医来源于中国古代经典，继承好经典才能治病；入门/提高/临床读的是同一批书"（★★★ 课程实录）。反对门派杂学。
2. **阳气论 / 扶阳派**：命门之火为根本，"病皆阳虚"倾向；反对滥投寒凉。需 Agent 5（医案）取证。
3. **大剂量经方**：主张仲景原方原量，反对轻剂试探。需医案交叉验证。
4. **医生须自立于不败**：上知天文下知地理中知人事；三医合一（医理命理地理）。
5. **师徒制传承**：反对纯学院派"考试毕业就上岗"，主张跟诊直到治好为止（学院官网：2008 年起佛州汉唐中医学院临床跟诊制）★★。
6. **孝道驱动**：研究玄学医道的动机自述为让父母少受苦（学生心得转述 ★）。
7. **不迷信"祖传秘方"**，只认经典 + 自己临床验证；"少而精"的药味（神农本草经 365 味，只用得准的）。
