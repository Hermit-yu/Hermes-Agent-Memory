# 哪吒面板风格说明卡片（用于技术模块通俗化说明）

适用：当用户要求把技术功能块做成"通俗易懂"时（如本次：M8 功能解释 + 上轮修的 bug 说明）。

## 卡片格式（已验证并嵌入面板）
每张卡片包含：
- 大标题（带表情符号 + 中文名，如 📊 指标上报 / 📈 监控看板）
- 通俗一句话（干嘛的，不堆术语）
- 技术一句话（源码确认，不夸大）
- 统一样式：浅色边框、圆角 12px、网格布局（auto-fit minmax(220px,1fr)）

已验证嵌入到以下位置：
- Monitor.vue（监控看板页，4 功能卡片 + 4 修说明）
- 扩展到全部 9 视图（Overview/Assets/Findings/Investigate/AiView/Plans/Audit/Settings/Monitor）

## 实现要点
1. 卡片内容直接写入 `<template>` 开头（插入到 `<template>
` 后第一行），不依赖外部组件
2. 样式用内联 style（避免引入新依赖），颜色变量：#ffdca3（标题）、#eae3d2（正文）、#bfa870（技术行）
3. 每张卡片独立，内容可直接从代码功能提取（如 metrics.php / Monitor.vue / agent.sh）
4. 不要用表格格式（用户要求不用表格），用网格卡片布局

## 用户偏好（本次确认）
主称"哥哥"、减少"宝宝"、直接简洁、中文回复、温暖但有边界。结果导向，不解释过程（除非用户明确要求细节）。
