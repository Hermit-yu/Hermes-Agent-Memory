# 前端交互功能检查清单

每个功能视图交付前的必检项（防止"只有描述没有实际功能"）：

## 数据绑定
- [ ] 文件包含 `fetch()` 或等效 API 调用（非空注释）
- [ ] 数据渲染使用 `v-for` / `.map()` / 循环（非静态 HTML 行）
- [ ] 数据变量在 `<script setup>` 中定义并初始化（非空对象）

## 构建与同步
- [ ] `npm run build` 完成无错误（检查控制台最后 3 行）
- [ ] `deploy/sync-site.sh` 完成（检查 nginx reload + fpm 结果）
- [ ] 构建产物大小有变化（非 0 字节变化 = 真实内容写入）

## 真实内容验证
- [ ] `curl -k --max-time 3` 站点返回内容包含功能名
- [ ] 浏览器刷新验证内容可见（非构建成功即止）
- [ ] 数据表行/列表项可渲染（非占位符 `-` 或空行）

## 大白话验收（用户明令标准）
- [ ] 页面无英文状态码/原始 JSON/§条款号裸奔（浏览器逐页点一遍，正则扫 innerText 确认）
- [ ] 翻译集中在一个 labels 字典，各页 import 同一字典（无散落的临时映射）
- [ ] 翻译键与后端真源对齐（后端白名单键 + DB 实际 DISTINCT 值各查过一遍）
- [ ] 透传列（详情/对象）有显示层翻译，布尔值与过长字符串有取舍，解析失败有兜底

## 用户风格
- [ ] 回复直接简洁（无"好的，我来"填充）
- [ ] 交付报告列具体模块（非泛泛"已修复"）
- [ ] 明确指出仍缺的交互（如表单提交、按钮功能）
