# Memory Import from External Repo

Procedure: clone repo, inspect memory/ + skills/ + .learnings/, copy skills to ~/.hermes/skills/, import memory via memory tool, include non-standard files (SOUL.md, AGENTS.md).

Pitfall: Memory tool has a per-entry char limit (~2200); monitor usage and consolidate/split rather than silently overflow. Private repos require auth — don't invent tokens.
