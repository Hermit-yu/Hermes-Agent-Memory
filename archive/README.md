# Archive / 历史归档

**English:** Non-active material kept for traceability. Nothing here is a runtime authority.

**中文：** 为追溯保留的非活跃材料。本目录内容不是运行时权威来源。

- `tmp/` — old drafts and temporary assets / 旧草稿与临时资产
- `reports/` — historical reports and inventories / 历史报告与盘点
- `persona-backups/` — dated persona backups / 带日期人格备份
