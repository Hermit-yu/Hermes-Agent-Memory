# OpenClaw / 智妍 迁移计划

目标：
- 把当前 TUF-PC 上的 OpenClaw + 工作区（智妍人格、记忆、自我提升项目等）平滑迁移到一台新的 Linux 服务器。
- 最大程度做到：**可回滚、少停机、不丢人格和记忆**。

## 迁移原则

1. **新环境先搭好，再切换流量**
   - 新服务器上先安装 OpenClaw、还原 workspace，再做连通性测试。
   - 旧环境在迁移期间保持可用，验证稳定后再切主通道。

2. **文件级同步，不依赖缓存/向量**
   - 真实人格和记忆来自：`SOUL.md` / `USER.md` / `memory/` / `projects/`。
   - 这些通过打包/解压方式迁移，不依赖内存缓存或索引。

3. **保留完整备份与回滚路径**
   - 不删除旧机上的任何关键数据，直到新环境连续稳定运行一段时间。
   - 如有问题，可以随时把通道切回旧环境。

## 目录说明

- `README.md`
  - 本说明，概述迁移目标与原则。
- `checklist.md`
  - 具体迁移步骤与待办事项（打包哪些内容、新机要做什么、如何回滚）。
- `backup/`
  - 后续用于存放迁移过程中的打包文件，例如：
    - `workspace-YYYYMMDD.zip`
    - `openclaw-config-YYYYMMDD.json`

> 说明：此目录是**内部执行手册**，你那份 Word 版可以视为“对外说明书”；两边内容可以互相补充。
