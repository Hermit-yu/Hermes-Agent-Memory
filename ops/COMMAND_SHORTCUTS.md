# 指令短语库（v1）

> 目标：一句话触发一整套动作，减少重复沟通。

## 立即可用短语

- **老规矩来一版**
  - 动作：按你偏好的语气与格式输出（短结论在前、可执行步骤在后）。

- **走省流模式**
  - 动作：减少解释、减少轮询、优先结果与关键提示。

- **给我打包交付**
  - 动作：集中归集交付文件，生成清单与入口说明，输出压缩包路径。

- **只报关键点**
  - 动作：仅在里程碑/风险变化/可用交付时汇报。

- **标准推进**
  - 动作：恢复常规节奏（结果+简短说明）。

## 备注
- 该短语库会持续扩展；每次新增会同步到《智妍使用手册》。
