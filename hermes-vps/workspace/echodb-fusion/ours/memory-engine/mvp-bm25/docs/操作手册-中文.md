# EchoDB 操作手册（中文）

## 一、初始化与重建
```bash
echodb memory reindex
echodb memory stats --json
```

## 二、回归验收
```bash
echodb memory regress
# 会写入 memory-echoDB/indexes/regression-report.json
```

## 三、自动调参
```bash
echodb memory tune
# 生成/更新 mvp-bm25/config/retrieval-profile.json
```

## 四、默认参数检索
```bash
echodb memory search "最近的 EchoDB 改动" --json
# 不传权重时自动使用 retrieval-profile
```

## 五、反馈 + 自学习
```bash
echodb memory feedback --query "最近的 EchoDB 改动" --id <id> --label up
echodb memory selflearn --once
```

## 六、安全边界
- 无 API key 时仍可运行（local-hash）
- forget 为 tombstone，不修改源 Markdown
- 可通过 `--scope` 做作用域检索隔离
