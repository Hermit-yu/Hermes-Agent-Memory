# EDICT 回滚手册

## 文件改动回滚
**适用**：批量编辑后结果不符合预期。
1. 立即停止后续批量任务。
2. 使用 git 恢复：`git restore <files>` 或 `git revert <commit>`。
3. 重新运行基础验证并记录回滚原因。
4. 追加审计记录，状态标记 `rolled_back`。

## cron 变更回滚
**适用**：定时任务改动导致错触发/漏触发。
1. 立即禁用新 cron 项并恢复上一个有效配置。
2. 校验下一次触发时间是否正确。
3. 补偿遗漏任务（如需人工触发一次）。
4. 记录变更窗口、影响范围、恢复时间。

## 外发误发回滚
**适用**：消息发错对象或内容。
1. 第一时间撤回（若平台支持）并发送更正说明。
2. 通知门下省和刑部进入事件审计。
3. 排查审批链与模板是否失效。
4. 输出事件复盘：误发原因、处置时延、预防动作。
