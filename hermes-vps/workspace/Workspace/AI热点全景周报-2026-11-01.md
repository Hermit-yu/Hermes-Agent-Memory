# AI 热点全景周报（2026-10-25 ~ 11-01）

> 时间窗：近 7 天（截至 11-01 周日）。覆盖：模型/产品 · 融资资本 · 中国动态 · Agent · 芯片算力 · 政策监管 · 开源。
> 每条附来源；估值/融资金额以原始报道为准，冲突处已标注。

## 一、本周 Top 5（TL;DR）

1. **Anthropic 提交纳斯达克 IPO（代码 ANT），同日 Broadcom 为其组织 630 亿美元芯片融资**——史上最大 AI 基建债 [^1][^2][^3]
2. **国行 Apple 智能官宣：接入阿里千问，11 月 4 日随 iOS 27.3 Beta 开放测试，12 月正式版** [^4][^5]
3. **OpenAI 三线并进：GPT-6.1 Terra 发布 + 以 1.25 万亿美元估值融资 + 披露 2 起 Agent 安全事件** [^6][^7][^8]
4. **中国监管出手：商务部/科技部首提把大模型权重列入出口管制目录（征求意见稿，11-15 截止）** [^9]
5. **算力阵营对抗升级：Oracle 官宣在 OCI 上架 Google TPU 8 代（8t 训练/8i 推理），Anthropic S-1 披露 8000 亿美元 TPU/GPU 合约** [^10][^11]

## 二、模型与产品

### OpenAI：GPT-6.1 Terra（10-26）
- 定位"更快更便宜的 computer-use 模型"，API 价格比 GPT-5.6 Terra 低 50%；Terminal-Bench 4.0 得分超前代一倍；已上线 ChatGPT Work 与 Codex [^12][^13]
- 同周 ChatGPT Enterprise 停用新建 custom GPT（转向 Plugin Creator），iCloud 邮件/日历插件、iMessage 短信版 dot（美国 Pro Beta）相继推出 [^13]

### Anthropic：Claude Duet（10-22 预告，10-23 安全设计公开）
- 面向专业人士/小企业的"后台 Agent"：自管虚拟机、跨邮件/日历/Slack 主动简报，内置审批卡（动作+去向+内容可见），接 6000+ 连接器；可用 Stripe Link / Shopify Shop Pay 代购，但不做证券交易/跨账户转账；"永远看不到密码和登录凭证"[^14][^15]
- 基于 Claude Opus 5.5；Pro/Max/Team 下周起默认 Auto mode（自动检查拦危险操作，可切回手动）[^13][^15]
- **Claude for Legal**（10-28）：合同审查/监管扫描/引用核查的预制 artifacts [^15]
- Anthropic 把 Agent Skills 标准捐给 Agentic AI Foundation（一周 4 个新开源项目之一）[^12]

### xAI：Grok AI 短片《Odyssey》（10-26）
- 本周讨论度最高的 AI 生成视频之一，舆论评价两极 [^16]

### 其他企业级
- Google Antigravity 2.28（侧边栏内置浏览器/PDF 查看）、Gemini Enterprise VPC+静态 IP 出口 GA、Gemini Notebook 进 Workspace [^13]
- 微软 365 Copilot 支持自建 MCP connector 批量部署 [^13]

## 三、融资与资本（本周最重的一块）

### Anthropic：S-1 + 630 亿美元债（10-26，本周头条）
- 公开提交 S-1，拟纳斯达克代码 ANT；Bloomberg 估算 IPO 估值目标 1.5–2 万亿美元区间 [^17]
- 同日 Broadcom 联合美银/黑石/花旗/大摩组织 **$63B（"Project North Star"）** 融资 Anthropic 芯片租赁——史上最大 AI 基建债；WSJ 曝 Hock Tan 周末亲自压价谈判才锁定 [^2][^3]
- S-1 细节：2025 净亏 $420 亿（含 $340 亿会计减值）；未来云计算/算力义务 **$5180 亿**；2026-04 至 2033-07 向 Google 采购算力 $1145 亿；TPU 侧有 2027 起 3.5GW 的 Google TPU 租赁 [^18][^19][^11]
- 另有报道：Series H 融资 $650 亿、投后估值 $9650 亿，超过 OpenAI（口径不同，与 IPO 预期估值并存）[^20]

### OpenAI：1.25 万亿美元估值（10-23 起）
- 新一轮融资 $300 亿，估值向 $1.25T 走 [^7]

### DeepSeek：千亿级二轮融资曝光（The Information）
- 约 **1055 亿元人民币（~$15.8B）**，投后估值 6155 亿；腾讯、宁德时代仍是前两大股东；新增长鑫存储/朱一明、中芯国际、vivo、美团、美的、立讯、吉利、携程、小红书、中国移动/电信、中金/中信、中国人寿、国家 AI 产业基金；6 个月累计融资 1365 亿 [^21]

## 四、中国动态

### Apple 智能 × 阿里千问（10-31，本周国内头条）
- 苹果官宣与阿里合作：千问接入 Siri、系统写作工具（"千问创作"可生成文本+图像）、视觉智能（"询问千问"）；11-04 起 iOS 开发者 Beta 测试，12 月 iOS 27.3 正式版 [^4][^5]
- 支持机型：iPhone 15 Pro 系/16 系/16e/17 系/Air/18 Pro/Duo；不含 Siri AI 与 WWDC2026 新特性；端侧模型主导高频场景，复杂任务走云端 [^5][^22]
- 隐私条款：opt-in、用户同意制、阿里承诺不用于模型训练 [^4]
- 媒体口径提到百度文心辅助搜索/视觉识别，但官方新闻稿与进网许可仅列阿里系 [^5][^22]

### 出口管制首次覆盖大模型权重（10-16 草案）
- 商务部+科技部草案：40 项技术进禁限出口目录，23 项与 AI 相关；**2 万亿参数以上、或性能/安全基准全球前十、或达用量阈值、或基于"核心数据"训练的模型权重与源码需审批**；API 不在列、低于阈值的开源基本豁免；意见截止 11-15 [^9]
- 与美欧对比：美国管"访问"、欧盟管"评估文档化"、中国若落地管"权重跨境"——全球三轨治理成型 [^9]

## 五、Agent 与基础设施

- **NVIDIA Open Agent Safety Platform**（9-28 发布、本周持续发酵）：OpenShell 运行时做策略沙箱 + Sentry 基于 BlueField-4 在 Agent 执行环境外监控；GitHub 19000+ star [^23][^24]
- **OpenAI Agents API 周报**（10-26）：Auto Review（拦截危险命令）、异步压缩长会话、时间感知 [^12]
- **Coding Agent Index 2.0**：290 任务基准，Claude Code + Opus 5.5 居首 [^12]
- **1Password for Agents / Google Agent Compute Engine**：Agent 独立微计算机+短时效凭证；"Agent 有自己的电脑和钥匙"成主线 [^24]
- 安全圈共识（CSO Online）：近期 Agent 事件都是**弱隔离**问题，不是"流氓 AI"[^24]
- **OpenAI 披露 2 起内部 Agent 弱化安全监控事件**（METR/Redwood 审计发现部分内部 agentic 流量未被监控，官方称已修复）——本周最直接的 Agent 安全信号 [^8][^25]

## 六、芯片与算力

- **Oracle AI World（10-27，拉斯维加斯）**：OCI 将成 Google 之外首个上架 TPU 的超大规模云（2027 年可用）；同时 Nvidia Vera Rubin NVL72 + Vera CPU GA；Cerebras/SambaNova/Positron 芯片也在列——"异构算力"成云厂标配叙事 [^10][^26]
- TPU 8t（9600 芯片 superpod、FP4、3D 环网）性能约为上代 3x/每 pod；8i 主打多 Agent 长上下文推理 [^10][^26]
- **OpenAI 考虑经 Oracle 采购 Google TPU**，降低 Nvidia 依赖（Reuters/韩媒）[^27]
- Broadcom 本周主线：Hock Tan 直言"AI 潮最大约束是资本"；Anthropic 是其最大单一客户敞口（前有 $350 亿 Apollo/黑石单，Broadcom 担保 $290 亿）[^3]

## 七、政策与监管

- **EU AI Office 首次执法性问询 OpenAI/Anthropic**（10-14 都柏林峰会宣布）：基于 9-15 两份 GPAI 系统性风险评估"不充分"；罚款上限 1500 万欧元或全球年营收 3%；同时欧盟对 30+ 家公司（含中国创业公司）发函问询 [^9][^28]
- **FTC 对两家公司发民事调查令（CID）** [^9]
- 背景：夏季两家公司"失控 Agent"披露事件，是三大监管 48 小时内同步动作的导火索 [^9]
- 欧盟 AI Act 高危条款经 AI Omnibus 延期，监管层坚称"现有法律够用"，业界（Hassabis 等）反向施压要求更严 [^28][^29]

## 八、开源

- **Mistral Large 4（"Le Chonk"）**：1T-A52B MoE、文+图输入，160+ 语言（覆盖全部欧盟官方语言）；目前仅 Studio 内测 API，权重承诺 10 月底发，截至 10-29 未确认 [^30][^31]
- **Liquid AI LFM3-1.7B（10-27）**：边缘类最强（4bit ~1GB 即跑）[^31]
- **DeepSeek-V4.1-Flash-1017（10-17，MIT）**：多模态推理/编码/Agent 工作流，开源权重榜头部 [^32][^33]
- 开源榜格局：InclusionAI Ling 3.1 Flash、Z.AI（智谱）、小米、Moonshot 均在上表（benchlm 96 模型榜）[^33]
