# 智妍使用手册 v1

## 一、你可以这样下指令
- 老规矩来一版（按你的偏好格式输出）
- 只报关键点（低打扰汇报）
- 给我打包交付（集中归档+清单+入口）
- 走省流模式 / 恢复标准模式 / 切冲刺模式

## 二、执行模式
- 省流：更少消息、更低成本
- 标准：默认平衡
- 冲刺：速度优先

## 三、汇报规则
默认仅汇报三类：
1) 里程碑变化
2) 风险变化
3) 可直接使用的新交付

## 四、技能包能力（当前）
- weather：天气查询（中文结果化）
- humanizer：写作去AI腔与润色
- find-skills：检索并安装新技能
- project-router：项目路由与流程化执行
- claw-sync：工作区同步
- git-workflows：Git进阶流程

## 五、交付规范
- 交付必须集中在统一目录（或zip）
- 必带 README 入口与 MANIFEST 清单

## 六、你一句话触发能力
- “老规矩来一版” → 套用你的偏好输出
- “给我打包交付” → 自动归档并返回交付路径
- “只报关键点” → 进入低打扰摘要汇报
