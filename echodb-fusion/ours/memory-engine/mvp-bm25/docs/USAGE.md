# 使用说明（MVP 阶段）

## 你会用到的命令

目标命令：
- `echodb memory search "<关键词>" --topK 20`

MVP 阶段会先提供一个可运行脚本版本，后续再把它封装成真正的 `echodb` 命令。

## 输出格式（建议）
每条结果包含：
- `score`：BM25 分数（可比较，不一定可跨库对比）
- `sourcePath`：来源文件
- `snippet`：命中片段（上下文）

## 常见问题

### 1) 为什么搜不到设备名/人名？
BM25 是关键词检索，拼写必须接近；后续会加入向量检索补强。

### 2) 索引文件为什么不进 Git？
因为索引可再生、可能包含碎片化内容、会膨胀仓库。真相源仍是 Markdown。
