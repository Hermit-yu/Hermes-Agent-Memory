# EchoDB 操作手册（中文）

## 日常运维

1. **重建索引**（首选）
   - `echodb memory reindex`
2. **检索**
   - `echodb memory search "EchoDB" --topK 20`
   - `echodb memory search "EchoDB" --scope global --mode hybrid`
3. **查看状态**
   - `echodb memory stats`
   - `echodb memory list --limit 5`

## 检索模式建议

- `--mode hybrid`：默认，通用场景。
- `--mode bm25`：关键词匹配更强。
- `--mode vector`：语义近似更强（当前为 local-hash MVP）。

可调参数：
- `--fusion rrf|weighted`
- `--bm25Weight 0.6 --vectorWeight 0.4`
- `--mmr`（去冗余）

## 数据治理

- 写入前噪声清洗默认开启（空行/模板噪声/重复）。
- 关闭清洗：`echodb memory reindex --disable-noise-filter`
- 忘记记忆（软删除）：`echodb memory forget --id <id>`
- 导出：`echodb memory export --out <file>`
- 审计日志：`memory-echoDB/indexes/audit-log.jsonl`

## 灾备 SOP

1. 确保 `memory-echoDB/daily`、`memory-echoDB/long-term` 完整。
2. 索引损坏时，无需手工修复索引文件。
3. 直接执行 `echodb memory reindex`。
4. 用 `echodb memory stats` 校验 docs/terms/scopes。
5. 必要时执行回归：`node .../scripts/regression.js`。
