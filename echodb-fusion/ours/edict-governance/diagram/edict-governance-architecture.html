三省六部治理架构图（OpenClaw × EchoDB）

体现“中书规划 → 门下审核 → 尚书执行调度”，并联动六部职能、预检闸门、审计与回滚闭环。

flowchart TB
    subgraph L0[决策层]
      U[皇上 / 任务发起人]
    end

    subgraph L1[治理核心（三省）]
      ZS[中书省\n任务拆解 / 风险分级]
      MX[门下省\n审核封驳 / 审批放行]
      SS[尚书省\n执行调度 / 结果回传]
    end

    subgraph L2[执行职能（六部 + 都察院）]
      HB[户部\n资源 / 配额 / 成本]
      LB[礼部\n规范 / 文书 / 模板]
      BB[兵部\n工程执行 / 文件变更]
      XB[刑部\n合规审计 / 红线拦截]
      GB[工部\n基础设施 / cron / 发布]
      DCY[都察院\n监督复核 / 抽检问责]
    end

    subgraph L3[执行控制层（策略与闸门）]
      PF[preflight-check\n预检 allow/deny]
      PE[POLICY_EFFECTIVE\n生效策略]
      AM[APPROVAL_MATRIX\n审批矩阵]
      TK[审批令牌 / 审批链\nL1 / L2 / L3]
      RB[ROLLBACK_PLAYBOOK\n回滚手册]
    end

    subgraph L4[工具执行层]
      T1[read / edit / write]
      T2[exec]
      T3[message.send.external]
      T4[cron add/update/remove]
    end

    subgraph L5[审计与资产层]
      AL[audit-log\n审计落盘]
      LG[edict-audit-log.jsonl]
      RP[任务报告 / 回归报告]
      DOC[RUNBOOK / DAILY_OPERATION_GUIDE]
    end

    U --> ZS
    ZS --> PE
    ZS --> AM
    ZS --> PF

    PF -- L1低风险直通 --> SS
    PF -- L2/L3高风险送审 --> MX
    MX -- 驳回/补充 --> ZS
    MX -- 批准 + 令牌 --> TK
    TK --> SS

    SS --> HB
    SS --> LB
    SS --> BB
    SS --> XB
    SS --> GB

    SS --> T1
    SS --> T2
    SS --> T3
    SS --> T4

    T1 --> AL
    T2 --> AL
    T3 --> AL
    T4 --> AL
    AL --> LG
    AL --> RP

    XB --> RB
    GB --> RB
    SS -- 异常/误发/故障 --> RB
    RB --> AL

    DCY -. 抽检/复核 .-> AL

    DOC --> ZS
    DOC --> MX
    DOC --> SS
